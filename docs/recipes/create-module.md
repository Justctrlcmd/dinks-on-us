# Create a module

First define the real capability, actor, lifecycle, invariants, queries, and authorization. Do not generate a full template automatically. Decide independently whether the feature needs a model/migration, FormRequests, resource, controller, transaction/service, routes, page/view, form, API service, query/mutation hook, navigation, and shared component.

Reuse the API envelope and fetch/query conventions. Add only justified relationships, indexes, status enums, and delete behavior. Test the smallest complete workflow plus validation, authentication, and failures. Update navigation and documentation only when the module genuinely needs them.
